# Rest API Server within V&A Museum
## Description
Assignment that I was required to do by my university where I researched and developed a Web-based client that uses a public API to search and browse. The public API used was Victoria & Albert Museum (V&A).
HTML, CSS AND JavaScript was used for this assignment.
